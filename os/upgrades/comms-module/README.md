# DFCD comms module (NFC + LoRa, Pico USB bridge)

A removable clamp-on module that adds **NFC/RFID** (PN532) and **LoRa** radio to
the deck. Because the DFCD rail bus only carries USB but those parts are
I2C/SPI, a **Raspberry Pi Pico inside the module** reads them locally and
presents to the deck as a single USB serial device. The deck drives it with
`deck-comms` — true hot-swap, like every other rail module, using the cheap
sensors.

```
  ┌─────────── comms module ───────────┐
  │  PN532 (NFC)  ──I2C──┐              │
  │                      ├── Pi Pico ──USB──▶ rail USB port ──▶ deck
  │  RFM9x (LoRa) ──SPI──┘   (firmware)│
  └─────────────────────────────────────┘
```

## Wiring (Pi Pico GPIO)

| From | Pico pin | Bus |
|---|---|---|
| PN532 SDA | GP4 | I2C0 |
| PN532 SCL | GP5 | I2C0 |
| RFM9x SCK | GP18 | SPI0 |
| RFM9x MOSI | GP19 | SPI0 |
| RFM9x MISO | GP16 | SPI0 |
| RFM9x CS | GP17 | — |
| RFM9x RST | GP20 | — |
| both 3V3 | 3V3 (pin 36) | — |
| both GND | any GND | — |

## Enclosure (in `../../../hardware-custom/Comms module/`)

Generated by `os/image/make_comms_module.py` (parametric — edit the dims block
and re-run). Two printed parts, both validated as watertight solids:

- **Comms module body** (82 × 60 × 32 mm) — Pico standoffs, an NFC read-through
  window (thinned front wall), an SMA hole (LoRa) on one end, a USB cable slot
  on the other, 4 lid bosses, and 2× M3 holes in the floor for the rail clamp.
- **Comms module lid** (82 × 60 × 3 mm) — screws onto the 4 bosses.

Print in PETG, 3 perimeters / 20% infill. The NFC window prints fine bridging
1.2 mm; keep that wall facing out so the reader works through it.

> **v1 / fit-check:** the floor bolt pattern (`BOLT_SPACING = 30 mm`) attaches
> to the deck's existing printed **picatinny rail clamp** (the same clamp the
> other modules use — measure yours and adjust the parameter before printing if
> it differs). The rail itself measures 12.4 × 26 mm. This is the one dimension
> to verify against a physical clamp before committing the print.

## Assembly

1. Set the PN532's onboard switches to **I2C**.
2. Flash the Pico — see `firmware/README.md` — and copy `boot.py` + `code.py`
   + the adafruit libs to the `CIRCUITPY` drive.
3. Wire PN532 and RFM9x to the Pico per the table above.
4. Mount the Pico on its standoffs; tuck PN532 against the NFC window, RFM9x by
   the SMA hole; fit the SMA antenna.
5. Route a short USB cable out the slot; close the lid (4× M3).
6. Bolt the module to a rail clamp; clamp it to a deck rail; plug the USB into a
   rail USB port.

## Use (from the deck)

```bash
deck-comms status            # NFC:ok LORA:ok  (confirms the module is seen)
deck-comms nfc               # tap a tag -> prints its UID
deck-comms lora tx "hello"   # transmit
deck-comms lora rx 60        # listen 60s
```

If `deck-comms` can't find it: confirm the USB cable is in a data-capable rail
port and the Pico shows a `CIRCUITPY` drive (firmware running).
